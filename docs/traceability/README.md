# Requirements Traceability Matrix

`rtm.csv` maps every section of the authoritative specification (§1–§84) to its target phase, ADRs, and — as phases progress — architecture, implementation, API, UI, database, tests, documentation, and acceptance criteria (spec §80).

Status values: `PLANNED` → `DESIGNED` → `IMPLEMENTED` → `VERIFIED` → `ACCEPTED`. A requirement is `VERIFIED` only when a test reference exists.
